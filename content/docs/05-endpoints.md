# 地址规则与多算力舱

看懂一个规则，就能推出算力舱上所有服务的地址。

## 基本规则

算力舱服务的域名固定为：

```
https://{服务名}-ai.{{BOX}}
        └─必以 -ai 结尾─┘└─ 你的微服域名 ─┘
```

| 服务 | 地址 |
| ---- | ---- |
| Ollama（模型 API） | `https://ollama-ai.{{BOX}}` |
| open-webui（聊天界面） | `https://open-webui.{{BOX}}` |
| ComfyUI（AI 绘图） | `https://comfyui-ai.{{BOX}}` |

> **注意**：`-ai` 后缀是算力舱服务与普通微服应用的最大区别。普通应用（如文件管理）的域名没有 `-ai`。

## 多个算力舱的情况

一台微服可以连接多个算力舱。此时需要用**前缀**指明具体哪一台：

```
https://f-{算力舱序列号}-{服务名}-ai.{{BOX}}
```

例如序列号为 `1420225016421` 的算力舱上的 Ollama：

```
https://f-1420225016421-ollama-ai.{{BOX}}
```

**在哪看序列号**：微服设置中的算力舱管理页面，每台设备都有唯一序列号。

> 只有一台算力舱时，两种写法等价，推荐用短地址。

## 服务名从哪来

`{服务名}` 是 AI 应用部署到算力舱时使用的服务标识，常见即 `ollama`、`open-webui`、`comfyui`。在应用详情或算力舱管理页面可以确认。不确定时，用本应用的**总览**页探测一下最快。

## 常见问题

### 浏览器直接打开 API 地址显示 404？

正常现象。`https://ollama-ai.{{BOX}}` 根路径只返回一行 "Ollama is running" 文本，具体功能都在子路径（如 `/api/tags`）。

### 提示连接被拒绝 / 无法访问？

1. 确认算力舱设备电源与网络正常
2. 确认对应 AI 应用已安装且未停用
3. 微服固件需 1.3.8 以上才支持跨应用反代（本应用"默认反代"模式依赖该能力）
4. 多算力舱环境请确认序列号前缀是否正确

### 网页里直接 fetch API 报跨域错误？

算力舱官方 Ollama 应用默认已放行跨域（`Access-Control-Allow-Origin: *`），浏览器可以直接 fetch。如果你自行部署的 Ollama 报跨域错误，在其设置中把 `OLLAMA_ORIGINS` 配置为 `*` 或你的页面来源即可；也可改由服务端 / 终端发起请求（无跨域限制）。

### API 地址和网页地址有什么区别？

- **API 地址**：给程序 / 客户端调用（`/v1`、`/api` 结尾）
- **网页地址**：给人用浏览器打开（如 open-webui 的聊天界面）

两者都是 `https://{服务名}-ai.{{BOX}}`，只是路径不同。

### 家里断网，局域网内还能用吗？

`heiyu.space` 域名的解析依赖 DNS，若无法解析可尝试使用微服局域网地址；具体取决于微服的 DNS 配置。日常使用建议保持微服联网。
