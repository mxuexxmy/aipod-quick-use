# 快速开始

从零到调用算力舱里的第一个模型，只需要三步。

## 算力舱是什么

算力舱是懒猫微服的 **AI 算力扩展设备**，内置 NVIDIA Jetson GPU。安装 AI 类应用后，模型会自动部署到算力舱上运行，享受本地 GPU 加速：

- **数据不出家门** —— 模型和数据都在自己设备上
- **无需 API Key 费用** —— 不依赖任何云端大模型服务
- **全家共享** —— 微服下的所有设备（电脑 / 手机 / 平板）都能调用

## 第一步：安装 Ollama

1. 打开微服的**应用商店**
2. 进入**算力舱分类**（或搜索 "Ollama"）
3. 安装 **Ollama** 应用

> Ollama 是最常用的本地大模型运行时，负责下载模型、加载模型并提供 API。绝大多数算力舱 AI 应用都基于它工作。

安装完成后，它的服务地址固定为：

```
https://ollama-ai.{{BOX}}
```

## 第二步：安装一个模型

模型相当于 AI 的"大脑"，需要单独下载。两种方式任选：

**方式 A · 用 open-webui 管理（推荐新手）**

在应用商店安装 **open-webui**（算力舱分类），打开它的管理页面即可搜索并一键下载模型。

**方式 B · 直接调用 API 下载**

在任意能访问微服的终端执行：

```bash
curl https://ollama-ai.{{BOX}}/api/pull -d '{ "name": "qwen3:4b" }'
```

### 模型怎么选

| 模型 | 参数规模 | 显存占用约 | 适合场景 |
| ---- | ---- | ---- | ---- |
| `qwen3:1.7b` | 1.7B | ~2 GB | 轻量任务、速度优先 |
| `qwen3:4b` | 4B | ~3 GB | 日常问答、文本处理（推荐入门） |
| `deepseek-r1:8b` | 8B | ~5 GB | 推理、数学、代码 |
| `qwen3:14b` | 14B | ~9 GB | 更高质量的长文写作与复杂任务 |
| `nomic-embed-text` | 137M | ~0.3 GB | 文本向量（Embedding），供知识库类应用使用 |

> 模型名可在 [Ollama 模型库](https://ollama.com/library) 查询，注意选择带量化（如 `q4_K_M`）的版本更省显存。

## 第三步：验证可用

打开本应用的 **API 验证** 页面：

1. 点击**开始检测**，确认服务在线
2. 选择刚安装的模型，发送一条测试消息
3. 看到流式回复即说明整条链路打通

也可以直接用 curl 试一下：

```bash
curl https://ollama-ai.{{BOX}}/api/chat -d '{
  "model": "qwen3:4b",
  "messages": [{ "role": "user", "content": "你好" }]
}'
```
